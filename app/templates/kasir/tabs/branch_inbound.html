Blokir Akses Cabang

Anda akan memblokir seluruh akses dari server cabang:

-

Dampak Pemblokiran

  • Server cabang tersebut langsung ditolak saat mengirim permintaan (HTTP 403 Forbidden).
  • Operator remote di cabang tersebut tidak dapat lagi memantau, membuka sesi, atau membaca data lokal server ini.
  • Anda dapat membuka kembali blokir ini kapan saja melalui menu ini.

Buka Blokir Cabang

Buka blokir akses untuk server cabang:

-

Setelah dibuka, server cabang ini akan dapat kembali terhubung dan mengoperasikan server ini sesuai otorisasi API Key yang sah.

Hapus Riwayat Koneksi

Hapus catatan riwayat koneksi masuk dari server cabang:

-

Catatan riwayat ini akan dihapus dari daftar. Jika server cabang tersebut menghubungkan diri kembali di masa mendatang dengan API Key yang valid, record baru akan otomatis dibuat.
